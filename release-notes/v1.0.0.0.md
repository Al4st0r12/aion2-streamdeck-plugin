## Update-Hinweis

- Charakter- und Shugo-Einstellungen zeigen die installierte Plugin-Version.
- Beim Öffnen der Einstellungen wird das neueste öffentliche GitHub-Release abgefragt.
- Wenn eine neuere Version verfügbar ist, führt ein Link zur Release-Seite, auf der der Installer geladen werden kann.
- Die letzte erfolgreiche Prüfung wird für 30 Minuten lokal zwischengespeichert. Bei fehlender Verbindung bleiben die Einstellungen nutzbar.
- Die Prüfung sendet keine Charakter- oder Kontodaten.

### Installation

Die Datei `AION-2-Stats-1.0.0.0.streamDeckPlugin` herunterladen und doppelklicken. Bereits gespeicherte Charakter- und Shugo-Einstellungen bleiben erhalten.
