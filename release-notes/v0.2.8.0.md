## Charakterverlauf bleibt erhalten

- Combat Power, Item-Level und Zeitpunkt der letzten erfolgreichen Aktualisierung werden je Charaktertaste in Stream Deck gespeichert.
- Änderungspfeile vergleichen auch nach einem Neustart mit dem vorherigen gespeicherten Stand.
- README ergänzt um den Link zur BBAION-Website.

### Installation

Die Datei `AION-2-Stats-0.2.8.0.streamDeckPlugin` herunterladen und doppelklicken. Die Shugo-Einstellungen und Charakterauswahl bleiben erhalten.
